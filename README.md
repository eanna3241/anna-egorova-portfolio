# Anna Egorova — Portfolio

Чистый проект портфолио на Next.js.

## Запуск

1. Открой папку проекта в Cursor.
2. Открой Terminal → New Terminal.
3. Выполни `npm install`.
4. Выполни `npm run dev`.
5. Открой `http://localhost:3000`.

## Где что менять

- `data/site.ts` — контакты и главный текст.
- `data/projects.ts` — карточки и содержимое кейсов.
- `data/about.ts` — карточки About.
- `styles/` — все размеры, цвета и адаптивность.
- `public/assets/` — изображения, иконки и шрифты.

Проектные категории: `mobile`, `web`, `presentation`, `graphic`, `concept`.
